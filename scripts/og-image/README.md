# Rafic link-preview card
`card.html` is the self-contained Sutur link-preview artwork using local fonts and images.
`replica.png` is the approved Rafic demo captured from the site.
`public/og.jpg` is rendered at 1200×630 with deviceScaleFactor 1 and JPEG quality 92, after fonts and images load.
Run from the repo root: `node scripts/og-image/render.mjs` (needs `npx playwright install chromium` once).
